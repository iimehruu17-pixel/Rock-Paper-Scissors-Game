# 🎮 Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer, test your luck, and see who wins!

## ✨ Features

- 🪨 Rock, Paper, and Scissors gameplay
- 🤖 Play against the computer
- 🏆 Automatic winner detection
- 📊 Score tracking
- 🎨 Simple and user-friendly interface
- ⚡ Interactive buttons and instant results

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Open the game in your browser.
2. Choose Rock, Paper, or Scissors.
3. The computer randomly selects its move.
4. The winner is decided according to the game rules:
   - Rock beats Scissors.
   - Scissors beats Paper.
   - Paper beats Rock.
5. Check the result and scores after each round.
